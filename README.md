# Aprende HTML a Mano

Una plataforma interactiva para aprender HTML desde cero hasta dominar la creación de tablas, diseñada específicamente para desarrollar **memoria muscular** escribiendo cada etiqueta a mano.

---

## Estructura de cada Lección
Para cada etiqueta estudiada, la interfaz presenta:
1. **Etiqueta en estudio**: Identificador visual de la etiqueta (ej. `<h1>`, `<p>`, `<a>`, `<img>`, `<table>`, `<th>`, etc.).
2. **Explicación & Sintaxis**: Qué hace la etiqueta y un bloque con su sintaxis oficial y atributos.
3. **Ejercicio práctico**: Instrucciones del desafío con pistas disponibles.
4. **Resultado esperado (Objetivo)**: Vista previa de cómo debe quedar el resultado visualmente.
5. **Editor de código "A Mano"**: 
   - **Bloqueo de copia y pega**: Bloquea clic derecho, `Ctrl+V`, `Cmd+V`, `Shift+Insert` y arrastrar y soltar texto.
   - Obliga al estudiante a escribir el código manualmente.
6. **Tu resultado en tiempo real**: Previsualización instantánea con renderizado en vivo.
7. **Comprobación y avance**: Validación inteligente con retroalimentación inmediata y navegación fluida a la siguiente lección.

---

## Iconografía
Se utiliza la librería oficial de **Bootstrap Icons** (`bi bi-*`) para todos los elementos de la interfaz:
- Indicadores de estado y advertencias (`bi-exclamation-triangle-fill`, `bi-slash-circle-fill`).
- Validaciones exitosas y errores (`bi-check-circle-fill`, `bi-x-circle-fill`).
- Secciones teóricas y ejercicios (`bi-question-circle-fill`, `bi-code-slash`, `bi-bullseye`, `bi-lightbulb`).
- Navegación y controles (`bi-arrow-left`, `bi-arrow-right`, `bi-moon-stars`, `bi-sun-fill`, `bi-trash3`).

## Temario Incluido
1. `<h1>` - Encabezados principales
2. `<p>` - Párrafos de texto
3. `<strong>` - Negrita y énfasis semántico
4. `<a>` - Hipervínculos y atributo `href`
5. `<img>` - Imágenes con atributos `src` y `alt`
6. `<ul>` y `<li>` - Listas desordenadas con viñetas
7. `<ol>` y `<li>` - Listas ordenadas numeradas
8. `<button>` - Botones interactivos
9. `<table>`, `<tr>` y `<td>` - Estructura básica de tablas
10. `<th>` - Tablas completas con celdas de encabezado
